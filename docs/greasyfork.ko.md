# OpenAI 상태 도우미

채팅 화면을 떠나지 않고 OpenAI 서비스의 공식 상태를 확인하세요. 이 독립적인 사용자 스크립트는 **status.openai.com**의 데이터를 사용합니다. OpenAI 제품이 아니며, 개인 계정이나 타사 사이트의 가용성을 측정하지 않습니다.

## 지원 사이트

- `chatgpt.com`
- `leopard-x.memofun.net`
- `mana-x.aizex.net`

## 표시 정보와 기능

- 자동 위치 모드에서는 작은 상태 버튼이 왼쪽 사이드바 옆에 배치되며, 사이드바를 펼치거나 접거나 너비를 바꾸면 함께 이동합니다. 화면이 좁으면 버튼이 화면 모서리에 표시되고, 패널은 화면 표시 영역을 벗어나지 않도록 크기가 제한됩니다.
- 공식 구성 요소 그룹, 현재 장애, 예정된 점검, 마지막으로 데이터를 성공적으로 가져온 시각을 표시합니다.
- 영어, 중국어 간체, 중국어 번체, 스페인어, 힌디어, 브라질 포르투갈어, 일본어, 한국어, 프랑스어, 독일어, 인도네시아어, 아랍어, 러시아어의 13개 인터페이스 언어를 지원합니다. 페이지나 브라우저의 언어를 자동으로 감지하거나 직접 선택할 수 있습니다. 아랍어는 오른쪽에서 왼쪽으로 표시되는 레이아웃을 사용합니다. 공식 장애 제목과 내용은 원문 그대로 표시하며, 번역 서비스를 사용하지 않습니다.
- 웹사이트의 밝은 / 어두운 테마를 따릅니다. 테마와 화면 모서리 위치를 직접 선택할 수도 있습니다. 키보드 조작을 지원하며 Escape 키로 패널을 닫을 수 있습니다.
- 페이지가 표시되는 동안 60초마다 새로고침하고, 백그라운드에서는 주기적인 조회를 중지합니다. 요청 제한 시간은 15초입니다. 새로고침에 실패하면 마지막으로 가져온 데이터를 캐시라고 명확히 표시합니다.
- 호환 데이터가 불완전하면 미확인으로 표시하며, 모든 서비스가 정상이라고 확인된 것처럼 표시하지 않습니다.

## 설치 및 사용

Tampermonkey 등의 사용자 스크립트 관리자를 설치한 후, 페이지 위쪽의 설치 버튼을 사용하세요. 지원 사이트를 열고 상태 버튼을 누르면 상세 정보를 볼 수 있습니다. 톱니바퀴 버튼으로 환경설정을 변경할 수 있습니다. 사용자 스크립트를 실행하기 위해 브라우저 설정이 필요한 경우에는 해당 관리자의 공식 설치 안내를 따르세요.

## 개인정보와 권한

상태 데이터는 `status.openai.com`에 보내는 익명 GET 요청으로 가져오며, 계정 Cookie를 포함하지 않습니다. 스크립트는 사이드바의 위치와 크기, 페이지의 언어 및 테마 속성만 확인합니다. 프롬프트, 대화, 계정 토큰을 읽거나 업로드하지 않습니다. 환경설정과 상태 알림의 중복 방지용 데이터만 로컬에 저장합니다. 분석 기능, 광고, 외부에서 받아 실행하는 의존 코드, 타사 번역 서비스를 포함하지 않습니다.

## 소스 코드 및 지원

[소스 코드, 문서, 문제 신고](https://github.com/laipeng101/openai-status-companion). MIT 라이선스를 사용합니다. 이 페이지에는 내용을 확인할 수 있는 완전한 사용자 스크립트가 게시되어 있습니다. 소스 코드와 설명은 GitHub push Webhook을 통해 자동으로 동기화됩니다. 설치와 업데이트는 Greasy Fork를 이용하세요.

테스트에는 자동 회귀 테스트, 데스크톱 및 390px 너비의 Chrome 테스트 페이지 확인, 공개 상태 데이터를 재생한 실제 Leopard-X 페이지의 레이아웃 통합 확인이 포함됩니다. 결과와 검증 범위는 저장소의 [검증 문서](https://github.com/laipeng101/openai-status-companion/blob/main/docs/validation.md)를 확인하세요. 지원 사이트가 변경되면 레이아웃도 달라질 수 있습니다.
