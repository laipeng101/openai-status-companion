# OpenAI 상태 도우미

채팅 화면을 떠나지 않고 OpenAI 서비스의 공식 상태를 확인하세요. 이 독립적인 사용자 스크립트는 **status.openai.com**의 데이터를 사용합니다. OpenAI 제품이 아니며, 개인 계정이나 타사 사이트의 가용성을 측정하지 않습니다.

## 지원 사이트

- `chatgpt.com`
- `leopard-x.memofun.net`
- `mana-x.aizex.net`

## 표시 정보와 기능

- 위치를 자동으로 설정하면 상태 버튼이 왼쪽 사이드바 옆에 표시되고 사이드바를 펼치거나 접을 때 함께 이동합니다. 버튼, 패널, 알림은 메뉴나 입력란을 가리지 않도록 이동하며, 공간이 부족하면 잠시 숨겨집니다.
- 서비스 구성 요소를 그룹별로 표시합니다. 현재 장애, 예정된 점검, 마지막으로 데이터를 가져온 시각도 확인할 수 있습니다.
- [인터페이스 언어](https://github.com/laipeng101/openai-status-companion/blob/main/docs/languages.md)를 직접 선택하거나 페이지 또는 브라우저의 언어를 따르도록 설정할 수 있습니다. 공식 장애 공지의 제목과 본문은 원문으로 표시합니다.
- 웹사이트의 밝은 / 어두운 테마를 따릅니다. 테마와 화면 모서리 위치를 직접 선택할 수도 있습니다. 키보드 조작을 지원하며 Escape 키로 패널을 닫을 수 있습니다.
- 페이지가 화면에 표시되는 동안 60초마다 서비스 상태를 업데이트합니다. 페이지가 백그라운드에 있으면 업데이트를 일시 중지합니다. 요청 제한 시간은 15초입니다. 업데이트에 실패하면 마지막으로 가져온 데이터를 캐시로 표시합니다.
- 이전 API를 사용하면 확인할 수 없는 장애 및 점검 정보는 미확인으로 표시합니다.

## 설치 및 사용

Tampermonkey 등의 사용자 스크립트 관리자를 설치한 후, 페이지 위쪽의 설치 버튼을 사용하세요. 지원 사이트를 열고 상태 버튼을 누르면 상세 정보를 볼 수 있습니다. 톱니바퀴 버튼으로 환경설정을 변경할 수 있습니다. 사용자 스크립트를 실행하기 위해 브라우저 설정이 필요한 경우에는 해당 관리자의 공식 설치 안내를 따르세요.

## 개인정보와 권한

상태 데이터는 `status.openai.com`에 보내는 익명 GET 요청으로 가져옵니다. 요청에 계정 쿠키를 포함하지 않습니다. 스크립트는 페이지 요소의 위치, 크기 및 표시 여부를 확인해 배치를 조정하고 페이지의 언어와 테마 설정을 읽습니다. 프롬프트, 대화 또는 계정 토큰을 읽거나 전송하지 않습니다. 설정과 중복 알림을 막기 위한 기록은 기기에 저장됩니다. 사용 추적, 광고, 외부에서 내려받아 실행하는 코드 또는 타사 번역 서비스는 포함하지 않습니다.

## 소스 코드 및 지원

[소스 코드, 문서, 문제 신고](https://github.com/laipeng101/openai-status-companion). MIT 라이선스를 사용합니다. 이 페이지에는 내용을 확인할 수 있는 완전한 사용자 스크립트가 게시되어 있습니다. 소스 코드와 설명은 GitHub push Webhook을 통해 자동으로 동기화됩니다. 설치와 업데이트는 Greasy Fork를 이용하세요.

자동 테스트와 함께 Chrome의 로컬 테스트 페이지에서 데스크톱 화면 및 너비 390픽셀 화면의 배치를 확인했습니다. 이전에 수집한 공개 상태 데이터를 사용해 실제 Leopard-X 페이지에서도 배치를 확인했습니다. 결과와 테스트 범위는 [검증 문서](https://github.com/laipeng101/openai-status-companion/blob/main/docs/validation.md)에서 확인할 수 있습니다. 사이트가 개편되면 배치가 달라질 수 있습니다.
