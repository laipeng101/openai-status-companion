# OpenAI 狀態助手

無需離開聊天頁面，即可查看 OpenAI 官方服務狀態。本獨立使用者腳本採用 **status.openai.com** 的資料，並非 OpenAI 官方產品，也不會測量個人帳號或第三方網站的實際可用性。

## 支援網站

- `chatgpt.com`
- `leopard-x.memofun.net`
- `mana-x.aizex.net`

## 顯示資訊與功能

- 自動位置模式下，小巧的狀態按鈕吸附在左側邊欄外側，隨側邊欄展開、收合或寬度變更跟隨定位。窄螢幕時，按鈕保持在畫面角落，面板尺寸則受可視範圍限制。
- 顯示官方元件分組、目前事件、排定維護，以及上次成功擷取資料的時間。
- 支援 13 種介面語言：英語、簡體中文、繁體中文、西班牙語、印地語、巴西葡萄牙語、日語、韓語、法語、德語、印尼語、阿拉伯語及俄語。可自動偵測網頁或瀏覽器語言，也可手動選擇。阿拉伯語採用由右至左的版面配置。官方事件標題與內文保留原文，不使用翻譯服務。
- 跟隨網站的淺色 / 深色主題，也可手動選擇主題與畫面角落位置。支援鍵盤操作，按 Escape 可收合面板。
- 頁面可見時每 60 秒重新整理，背景分頁暫停輪詢。請求逾時為 15 秒。重新整理失敗時，保留上次擷取的資料並明確標示為快取。
- 相容資料不完整時明確標示「未核實」，不會顯示為已確認所有服務正常。

## 安裝與使用

先安裝 Tampermonkey 等使用者腳本管理器，再使用頁面上方的安裝按鈕。開啟支援網站，按一下狀態按鈕即可檢視詳情；齒輪按鈕可調整偏好設定。如果管理器需要在瀏覽器中完成額外設定才能執行使用者腳本，請依照其官方安裝說明操作。

## 隱私與權限

狀態資料僅透過匿名 GET 請求存取 `status.openai.com`，不攜帶帳號 Cookie。腳本只檢查側邊欄的位置與尺寸，以及頁面的語言、主題屬性，不會讀取或上傳提示詞、對話或帳號權杖。僅在本機儲存偏好設定與狀態通知的去重資料。不含分析追蹤、廣告、從遠端取得並執行的相依程式碼，或第三方翻譯服務。
