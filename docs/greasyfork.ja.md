# OpenAI ステータスアシスタント

チャット画面を離れずに、OpenAI サービスの公式な稼働状況を確認できます。この独立したユーザースクリプトは **status.openai.com** のデータを使用します。OpenAI の製品ではなく、個人アカウントや第三者サイトの可用性を測定するものでもありません。

## 対応サイト

- `chatgpt.com`
- `leopard-x.memofun.net`
- `mana-x.aizex.net`

## 表示内容と機能

- 位置を自動にすると、ステータスボタンは左サイドバーの横に表示され、サイドバーの開閉に合わせて移動します。ボタン、パネル、通知はメニューや入力欄などを避けて表示され、空きがなければ一時的に非表示になります。
- サービスの構成要素をグループ別に表示し、対応中の障害、メンテナンス予定、前回データを取得できた日時を確認できます。
- [表示言語](https://github.com/laipeng101/openai-status-companion/blob/main/docs/languages.md)は手動で選ぶか、ページやブラウザーの設定に合わせられます。公式の障害情報はタイトルも本文も原文のまま表示します。
- サイトのライト / ダークテーマに追従します。テーマや画面の隅への配置は手動でも選択できます。キーボード操作に対応し、Escape キーでパネルを閉じられます。
- ページを表示している間は稼働状況を 60 秒ごとに更新し、バックグラウンドでは更新を停止します。応答が 15 秒以内にない場合、通信はタイムアウトします。更新に失敗した場合は、前回のデータをキャッシュとして表示します。
- 旧 API を使う場合、確認できない障害情報やメンテナンス情報は「未確認」と表示されます。

## インストールと使い方

Tampermonkey などのユーザースクリプト管理ツールをインストールし、ページ上部のインストールボタンを使用してください。対応サイトを開き、状態ボタンを押すと詳細を表示できます。歯車ボタンから設定を変更できます。ユーザースクリプトを実行するためにブラウザー側の設定が必要な場合は、管理ツールの公式インストール手順に従ってください。

## プライバシーと権限

稼働状況は `status.openai.com` への匿名 GET リクエストで取得します。アカウントの Cookie は送信しません。スクリプトは画面上の要素の位置やサイズ、表示状態に合わせて配置を調整し、ページの言語とテーマの設定を参照します。プロンプト、会話、アカウントのトークンを読み取ったり送信したりすることはありません。設定と通知の重複を防ぐための記録は端末に保存されます。利用状況の追跡、広告、外部から取得して実行するコード、第三者の翻訳サービスは含まれません。
