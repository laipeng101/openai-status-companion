# OpenAI ステータスアシスタント

チャット画面を離れずに、OpenAI サービスの公式な稼働状況を確認できます。この独立したユーザースクリプトは **status.openai.com** のデータを使用します。OpenAI の製品ではなく、個人アカウントや第三者サイトの可用性を測定するものでもありません。

## 対応サイト

- `chatgpt.com`
- `leopard-x.memofun.net`
- `mana-x.aizex.net`

## 表示内容と機能

- 自動位置モードでは、小さな状態ボタンを左サイドバーの横に配置し、サイドバーの展開、折りたたみ、幅の変更に追従します。画面幅が狭い場合はボタンを画面の隅に配置し、詳細パネルが表示領域からはみ出さないようにします。
- 公式コンポーネントのグループ、進行中のインシデント、予定メンテナンス、最終取得成功日時を表示します。
- 表示言語は英語、簡体字中国語、繁体字中国語、スペイン語、ヒンディー語、ブラジルポルトガル語、日本語、韓国語、フランス語、ドイツ語、インドネシア語、アラビア語、ロシア語の 13 言語です。ページやブラウザーの言語を自動検出するほか、手動でも選択できます。アラビア語は右から左のレイアウトを使用します。公式インシデントのタイトルと本文は原文のまま表示し、翻訳サービスは使用しません。
- サイトのライト / ダークテーマに追従します。テーマや画面の隅への配置は手動でも選択できます。キーボード操作に対応し、Escape キーでパネルを閉じられます。
- ページを表示している間は 60 秒ごとに更新し、バックグラウンドではポーリングを停止します。リクエストのタイムアウトは 15 秒です。更新に失敗した場合は、前回取得したデータをキャッシュと明示して表示します。
- 互換データが不完全な場合は「未確認」と明示し、すべて正常と確認できたかのようには表示しません。

## インストールと使い方

Tampermonkey などのユーザースクリプト管理ツールをインストールし、ページ上部のインストールボタンを使用してください。対応サイトを開き、状態ボタンを押すと詳細を表示できます。歯車ボタンから設定を変更できます。ユーザースクリプトを実行するためにブラウザー側の設定が必要な場合は、管理ツールの公式インストール手順に従ってください。

## プライバシーと権限

状態データは `status.openai.com` への匿名 GET リクエストで取得し、アカウントの Cookie は送信しません。スクリプトが確認するのはサイドバーの位置やサイズ、ページの言語・テーマ属性のみです。プロンプト、会話、アカウントトークンを読み取ったりアップロードしたりしません。ローカルに保存するのは設定と状態通知の重複防止用データだけです。アクセス解析、広告、外部から取得して実行する依存コード、第三者の翻訳サービスは含まれません。

## ソースコードとサポート

[ソースコード、ドキュメント、問題報告](https://github.com/laipeng101/openai-status-companion)。MIT ライセンスです。このページには、内容を確認できる完全なユーザースクリプトを掲載しています。ソースコードと説明文は GitHub の push Webhook を通じて自動同期します。インストールと更新には Greasy Fork を使用してください。

テストには自動回帰テスト、デスクトップおよび幅 390px の Chrome テスト用ページでの確認、公開ステータスデータを再生した実際の Leopard-X ページでのレイアウト連携確認が含まれます。結果と検証範囲は、リポジトリの[検証ドキュメント](https://github.com/laipeng101/openai-status-companion/blob/main/docs/validation.md)をご覧ください。対応サイトの更新により、レイアウトが変わる場合があります。
