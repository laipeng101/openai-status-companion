# OpenAI 状态助手

[English](README.md)

在 **chatgpt.com**、**leopard-x.memofun.net** 和 **mana-x.aizex.net** 显示 OpenAI 官方服务状态的独立用户脚本。本项目并非 OpenAI 或第三方站点官方产品。

## 功能

- 桌面端默认显示在边栏外侧，跟随边栏伸缩、折叠及应用外壳替换；窄屏保持在视口角落，也可手动选择左下或右下位置。
- 显示官方组件分组、进行中事件、计划维护和本地获取时间。事件标题、正文保留官方原文。
- 提供英文、简体中文界面，可跟随网页或浏览器语言，也可手动选择并保存。
- 跟随网站明暗主题，支持手动切换；使用 Shadow DOM 隔离样式，支持键盘操作及减少动态效果偏好。
- 可见页面每 60 秒刷新；后台暂停轮询，返回时按数据年龄刷新。请求超时为 15 秒。
- 请求失败保留上次成功数据并明确标注缓存。兼容数据缺少事件或维护字段时标注“未核验”，不会显示成已核验的全部正常。

## 安装与使用

通过 [Greasy Fork 页面](https://greasyfork.org/zh-CN/scripts/603564-openai-status-companion)安装，需要 Tampermonkey 等用户脚本管理器。打开支持的站点，点击状态按钮查看详情；齿轮按钮可设置语言、主题和位置，Esc 收起面板。

**从旧版“OpenAI 官方状态中文提示（aizex）”1.6.2 迁移：**新版名称及命名空间形成新的脚本身份，安装后请停用旧脚本。新版会提示旧面板同时存在，但不会替你修改其他脚本的设置。

## 数据与隐私

所有状态请求仅发往 `https://status.openai.com/`，匿名且不携带 Cookie。新版官方页面仅作为静态 JSON 数据解析，不执行其脚本；旧 JSON 接口仅作回退，并逐项标注是否核验。事件链接仅允许官方状态域名。

脚本不读取或上传对话、提示词、账号令牌或页面正文；只检查边栏几何尺寸及主题、语言属性。语言、主题和位置偏好存于脚本管理器，状态提醒指纹存于 sessionStorage。不含统计、广告、远程可执行依赖或翻译服务。官方事件正文不经机器翻译。

官方数据反映汇总可用性，不能证明个人账号、指定模型或第三方站点的实际可用性。

## 开发及语言扩展

使用 Node.js 22.12+ 或 24+：运行 `npm ci` 后执行 `npm run check`；`npm run preview` 启动本地布局预览。

源码位于 `src/`，构建产物为完整、非压缩的 `dist/openai-status-companion.user.js`。Greasy Fork 同步完整文件，运行时没有外部代码依赖。esbuild 和 jsdom 仅用于开发。

在 `src/locales.js` 添加语言注册项，包含 `label`、`lang`、`dir`、`messages`、`componentNames` 与 `groupNames`。保持英文字典的键名及 `{占位符}`，缺失项回退英文；同时增加脚本元信息及发布页说明。每种新增语言均需检查窄屏布局；`dir: 'rtl'` 为后续从右向左语言预留。

发布流程见[发布说明](docs/publishing.md)，版本变更见[更新日志](CHANGELOG.md)。MIT 许可。
