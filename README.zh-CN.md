# OpenAI 状态助手

[English](README.md)

在 **chatgpt.com**、**leopard-x.memofun.net** 和 **mana-x.aizex.net** 显示 OpenAI 官方服务状态的独立用户脚本。本项目并非 OpenAI 或第三方站点官方产品。

## 功能

- 自动模式下，状态按钮跟随左侧栏，也可选择左下或右下作为首选位置。状态按钮、详情和提醒会避开原生菜单、输入框及其他可见控件，空间不足时临时隐藏。
- 按组显示服务组件，并列出尚未解决的服务异常、计划维护和查询时间。官方通报的标题和正文保留原文。
- 界面可跟随网页或浏览器语言，也可手动选择并保存。[支持的语言](docs/languages.md)
- 跟随网站明暗主题，支持手动切换；使用 Shadow DOM 隔离样式，支持键盘操作及减少动态效果偏好。
- 页面可见时每 60 秒更新状态，切到后台时暂停。回到页面时，如果数据已过时就会刷新。请求超时为 15 秒。
- 刷新失败时会保留并标注上次获取的缓存数据。使用旧版接口时，无法确认的服务异常或维护信息会标为“未核验”。

## 安装与使用

通过 [Greasy Fork 页面](https://greasyfork.org/zh-CN/scripts/603564-openai-status-companion)安装，需要 Tampermonkey 等用户脚本管理器。打开支持的站点，点击状态按钮查看详情；齿轮按钮可设置语言、主题和位置，Esc 收起面板。

## 数据与隐私

所有状态请求仅发往 `https://status.openai.com/`，以匿名方式发送，且不携带 Cookie。脚本只从官方状态页读取 JSON 数据，不执行该网页的脚本。无法读取状态页时，会改用旧版接口，并分项标注核验结果。事件链接仅允许指向官方状态域名。

脚本根据页面元素的位置、尺寸和显示状态调整布局，并读取页面的语言和主题设置。脚本不会读取或上传对话、提示词、账号令牌或页面正文。语言、主题和位置保存在脚本管理器中，用于避免重复提醒的记录保存在当前标签页的会话存储中。脚本不包含使用情况统计、广告、远程可执行代码或翻译服务。

官方数据反映汇总可用性，不能证明个人账号、指定模型或第三方站点的实际可用性。

## 开发及语言扩展

使用 Node.js 22.12+ 或 24+：运行 `npm ci` 后执行 `npm run check`；`npm run preview` 启动本地布局预览。

源码位于 `src/`，构建产物为完整、非压缩的 `dist/openai-status-companion.user.js`。Greasy Fork 同步完整文件，运行时没有外部代码依赖。esbuild 和 jsdom 仅用于开发。

在 `src/locales/` 添加语言包，并在 `src/locales/index.js` 注册。构建会根据注册表和语言包生成脚本元数据及语言表。语言包格式、发布页说明和验证步骤见[语言维护指南](docs/languages.md#adding-a-language)。

发布流程见[发布说明](docs/publishing.md)，版本变更见[更新日志](CHANGELOG.md)。MIT 许可。
